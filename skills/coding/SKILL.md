# Coding & Agentic Development Skill

**Brand**: GRUMMAN AI / GerdsenAI. Local-first. Sourced claims only.

## Principles
1. Prefer local inference (Ollama, vLLM, LM Studio) over hosted when possible.
2. Document evidence for any claim about performance, APIs, or hardware.
3. No GitHub Actions. Use local scripts or manual processes.
4. Secure inter-app: MCP, Tailscale, Dot receipts.
5. Preserve branding in all outputs (docs, GUIs, screenshots).
6. When consolidating issues: inventory all pages, classify (keep/integrate/archive), preserve history, link duplicates, update in place.
